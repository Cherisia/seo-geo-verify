Schema.org vocabulary data

The bundled `src/core/schema-context.json` and `schema-vocabulary.json` derive from Schema.org, retrieved on 2026-09-17. The latter retains type inheritance and property ranges; labels, comments and unrelated fields were omitted. The context was compacted as JSON. Neither file is fetched from a target website during an audit.
